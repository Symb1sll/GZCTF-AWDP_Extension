## 本次发布整理

1. 与本地原始 v1.2.5 基线比对得到 24 个集成文件，附录限制的 5 个文件未修改、未收入仓库。
2. 发布覆盖层，排除完整上游、缓存、产物、私有配置、数据和历史备份。
3. 按最终记录补入测试 `web-entry`、攻击网络和网络校验；新初始化配置直接使用已确认网络名，这是发布整理版本，不是从服务器重新下载的声称。
4. `/healthz` 改为首页检查，并明确首页 200 不是完整健康或计分验收。
5. 正式工具的固定 image ID 改为必填 `--expected-image-id`，部署者提供已验收 ID；目录/服务名仍沿用原方案，不是通用迁移器。
6. 修复旧 README 编码，重写不含个人路径/真实地址的说明。SQL 显式连接 `gzctf`，依据本地 schema，修正版无独立历史回传。
7. 新增覆盖层安装器和测试，不自动提交/推送，不运行服务器切换。
8. 本地示例包生成器显式设置 checker 输出 UTF-8，并核对 `AWDP_RESULT`，避免 Windows 编码错误或将 checker 异常退出当成预期失败；补丁输出使用兼容 Python 3.8 的文件接口。
9. 新增正式接入只读预检：原运行版本标记、7 条基线数据库迁移记录、同机 rootful Docker / AppArmor 及数据库网络条件。历史切换未回传这些完整检查，不将新增逻辑写成旧流程已执行的事实。
10. 生产 Compose 校验移至写入前，测试初始化与生产准备采用私有暂存目录发布，正常失败保留暂存、允许排障后重试；不自动删除旧目录。对应本地模拟测试不代表重新做了生产部署。
11. 覆盖层安装器同时复制公开 `docs/`，修复安装后 AWDP README 文档链接；入口检查新增有限启动等待。README 集中列出版本、网络、存储、镜像白名单、错误数据库和回退等部署陷阱。

本次检查结果在仓库外审查报告中，避免把随后可能变化的结果写成永久保证。本次没有重新构建全部 Docker 镜像或在服务器重部署，换版本/服务器仍须验收。
